# 人物

本目录用于保存单人物档案：人物自身的性格、认知、欲望、恐惧、成长、外貌与信息边界。

人物之间的互动优先放入 `04_人物关系/`；跨人物的能力协作放入 `05_能力与成长/`；已确认的不可冲突设定放入 `08_决策记录/`。

## 当前档案

- `外貌设定_亚历克西斯与伊莲娜.md`：整合 Alexis / Eleanor 与 Ilena White 的外貌机制、Ilena 五官、Alexis 一至四年级外貌演变、人体变形与生长关系，以及第四部圣诞舞会造型。该文件明确区分现行修订方向与 26.10.2 原稿中的旧伪装机制。

后续建立或扩展人物档案时，必须继续区分原稿事实、现行修改方案与已确认设定。
