## 目录入口

- `01_原稿/`：作者小说原稿；当前批次为 `26.10.2`。
- `02_总体结构/`：跨卷连续性、群像与世界线、七部结构接口。
- `03_人物/`：单人物档案、性格与个人发展。
- `04_人物关系/`：关系网、情感线、家庭及阵营关系。
- `05_能力与成长/`：魔法、发明、治疗等能力曲线、合作结构与边界。
- `06_分部修改方案/`：各分部现行修改说明、重构大纲与施工索引。
- `07_专题/`：跨分部但不适合归入单一关系/能力/卷别的专题。
- `08_决策记录/`：已确认设定、已否决方案、待裁决问题、设定变更日志。
- `09_讨论存档/`：需要追溯理由时使用的讨论记录。

## 新会话读取顺序

1. 先读本 README 与 `项目规范.md`。
2. 再读 `08_决策记录/已确认设定.md`；有冲突风险时读 `待裁决冲突.md`。
3. 读取当前问题直接涉及的总体结构、人物、关系、能力或分部修改文件。
4. 必要时读取 `01_原稿/26.10.2/` 下对应原稿。
5. 只有需要追溯理由时才读 `09_讨论存档/`。

不得把 AI 草稿或讨论中的候选方案直接当作作者立场；不得用历史讨论覆盖已确认设定；不得以“记得原稿”为由跳过实际读取。
