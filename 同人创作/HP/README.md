# HP 同人小说工作区

> 当前原稿归档批次：**26.10.2（2026-10-02）**。

本目录保存 HP 同人小说的原稿、人物设定、人物关系、能力发展、分部修改方案和讨论决策。

## 目录入口

- `01_原稿/`：作者小说原稿；当前批次标记为 `26.10.2`。
- `02_总体结构/`：七部结构、故事总纲、伏笔与回收。
- `03_人物/`：人物档案、性格与个人发展。
- `04_人物关系/`：关系网、情感线、家庭及阵营关系。
- `05_能力与成长/`：魔法、发明、魁地奇等能力曲线及边界。
- `06_分部修改方案/`：第一至第七部的现行修改方案。
- `07_专题/`：跨分部的重要专题。
- `08_决策记录/`：已确认设定、已否决方案、待决定问题。
- `09_讨论存档/`：按日期归档的讨论记录。

## 新会话读取顺序

1. 先读本 README 与后续建立的项目规范。
2. 再读 `08_决策记录/已确认设定.md`。
3. 读取当前问题直接涉及的人物、关系、能力或分部修改文件。
4. 必要时读取 `01_原稿/26.10.2/` 下对应原稿。
5. 只有需要追溯理由时才读 `09_讨论存档/`。

不得把 AI 草稿或讨论中的候选方案直接当作作者立场，也不得用历史讨论覆盖已确认设定。
