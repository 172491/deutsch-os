# 第一部 v1.0｜修改说明补充：Weston 家庭背景与 Alexis 入家史

> 本文件记录第一部重修必须前置的 Weston 家庭背景。它覆盖 26.10.2 原稿中“Vincent 是 Ilena / Roland 的舅舅、因妹妹去世而收养双胞胎”的旧家庭结构。正式改写第一部时，以本文件为当前家庭背景基线；未明确决定的项目仍保留为待定，不提前写死。

## 一、Weston 家族基础

Weston 家是英国历史较久的旧勋贵 / 上流家庭，拥有稳定而长期积累的家产，但不属于魔法界纯血世家，也不能直接套用 Malfoy 式“巫师贵族”社会逻辑。

家庭主要成员：

- Angelina Weston：家中祖母辈，丈夫 Alex 已去世。
- Vincent Weston：Angelina 的儿子。
- Linda Weston：Vincent 的妻子。
- Clara：Vincent 的姐姐，比他大约七至八岁。
- Ilena White、Roland White：Clara 的双胞胎子女，保留 White 姓。
- Alexis Angelina Weston：后来被 Vincent / Linda 收养；中间名 Angelina，由 Angelina 命名。

Weston 家在伦敦有长期住宅，在英国其他地区拥有多处别墅 / 乡间庄园；家庭资产足以维持私人跑马场、长期旅行、艺术与教育投入。Alexis 小时候学骑马可直接在自家跑马场完成。

财富只提供生活条件，不能把全家写成“什么都能靠钱解决”。他们真正塑造 Alexis 的部分是稳定日常、文化教育、被认真对待和被允许回家的家庭结构。

## 二、Angelina 与上一代

Angelina 的丈夫名为 Alex，已经去世。Alexis 的名字由 Angelina 所取，直接纪念亡夫 Alex；她的中间名为 Angelina。

这层命名应当具有家庭接纳意义：这个孩子不是临时被带回来的“孤儿”，而是在取得新名字时就被正式放进 Weston 家的家族记忆里。

Angelina 本人应保留原稿里已经存在的教育功能：她重视阅读、审美、生活秩序与个人空间。原稿中“用你读过的书填满书房，也填满你自己的内心”的家庭教育气质可以继续保留，但需要接入新的家族关系。

Alexis 十岁时，Angelina 因年事已高去世。Alexis 为此悲伤很久，曾把自己关在房间里、减少社交。真正把她慢慢拉回日常的不是一次谈心，而是 Ilena 与 Roland 长期陪她说话、每天拉她出门，让生活一点点重新恢复。

这件事应成为第一部开学前状态的重要前史：Alexis 已经经历过一次“被爱的人自然离世”，因此她对家庭的依恋很深，却并不意味着她会轻易向外人展示这种依恋。

## 三、Vincent × Linda：婚姻与职业背景

Vincent 与 Linda 在 Cambridge 就读时认识。

- Linda 高 Vincent 一级，主修文学。
- Vincent 学习艺术品修复。
- 两人可能在学校相关展览 / 艺术活动中正式相识，由 Vincent 主动追求。
- 追求持续数年，Linda 硕士毕业后两人结婚。

Linda 在硕士阶段已经开始做编剧，后转向写作，逐渐成为职业作家。她后来的儿童作品创作与孤儿院取材、Alexis 的进入有直接关系。

Vincent 出身富裕，缺乏明确的传统职业野心。最初只是替 Linda 拍照、画作品封面或处理视觉设计，后来逐渐真正喜欢上绘画与摄影，因此形成设计师 / 摄影师方向的职业身份。

这对夫妻的关系不写成“一个负责挣钱、一个负责艺术”。两人都长期处在创作、审美和文化环境里，家庭中大量书籍、照片、画作、音乐、旅行和展览因此是自然生活的一部分。

## 四、Clara 一家与 Ilena / Roland 的进入

Clara 比 Vincent 大约七至八岁。她结婚后生下双胞胎 Ilena 与 Roland。

双胞胎八岁那年，Clara 与丈夫因车祸同时去世。

### 当前确定

- 当时 Vincent 与 Linda 已结婚约三年，尚无自己的孩子。
- Weston 与 Clara 一家的关系一直很好，不存在“出事后才突然承担责任”的陌生感。
- Vincent、Linda 与 Angelina 共同决定把两个孩子接回家生活。
- 不强迫改姓：Ilena 与 Roland 继续使用父母留下的 White 姓。
- 三位成年人明确表示，等他们长大以后可以由他们自己决定是否改姓；家庭归属不依赖姓氏统一。

### 暂不写死

- 车祸背后是否另有故事，目前只作为可能的长期伏笔，不在第一部提前暗示成阴谋。
- 不提前决定事故是否与魔法界有关。

这段经历解释了为什么 Weston 家对“收养后是否改姓、家庭身份是否需要靠血缘证明”天然有成熟经验，也为后来 Alexis 保留 Weston 身份提供家庭层面的先例。

## 五、为什么后来考虑收养孩子

Ilena 与 Roland 十四岁时，Vincent 与 Linda 仍然没有自己的孩子。

双方其中一方或双方是否存在明确生育问题，当前不确定；第一部不要自行诊断或设定具体医学原因。只需确定：多年婚姻后，他们已经现实地接受“可能不会拥有亲生孩子”这一可能。

Linda 为小说取材需要前往孤儿院，由此提出是否认真考虑领养一个孩子。

Vincent 最初不赞成。

他的反对不应写成“嫌弃孤儿”或阶层偏见，更适合来自对责任的谨慎：他们已经共同养育 Ilena / Roland，多一个受过创伤、背景未知的孩子不是一时冲动可以决定的事情。

Angelina 的态度较开放：只要年轻人自己认真决定，她不会反对。

最后参与实地走访的是 Vincent、Linda、Ilena 与 Roland 四人。他们没有对孤儿院公开说“今天就是来选孩子”，而是以 Linda 取材为由访问几家机构，同时观察自己是否真的愿意把一个孩子带回家。

他们一开始想象中的对象更小，大约三四岁，甚至更年轻。

前几家孤儿院里，没有哪个孩子让四个人形成“我们希望这个人进入家里”的一致感觉。

## 六、遇见 Jane / Eleanor：不是“挑中最聪明漂亮的孩子”

到第四或第五家孤儿院时，Ilena 先注意到了 Jane——当时的 Eleanor。

她最先看到的不是天赋，而是异常：

- 反应明显笨拙、迟缓；
- 对周围人的靠近具有不自然的防御或迟钝；
- 明显遭受过虐待与其他孩子的霸凌；
- 身体瘦小到让 Ilena 误以为她只有五六岁。

Ilena 将情况告诉 Vincent 与 Linda。两位成年人进一步确认后，当下改变了原本“只是取材 / 观察”的态度，决定正式推进收养，同时举报孤儿院。

他们原本期待的是一个更年幼的孩子，因此得知 Jane 实际已经七八岁时，不应出现“年龄太大所以犹豫”的戏码；正确反应是更强的心疼——她已经比外表看起来大，却被长期营养不良和虐待压成了更幼小的身体状态。

这次收养的因果重点是：**他们不是因为发现她天才、漂亮或有特殊身份而选择她，而是先看见一个正在被伤害的具体孩子。**

## 七、Alexis Angelina Weston：新名字与最初一个月

Angelina 为她取名 Alexis，以纪念亡夫 Alex；中间名为 Angelina。

新名字不用于“覆盖 Eleanor”。在当时的家庭视角里，他们并不知道 Eleanor Potter 的身份；对孩子本人而言，Alexis 是被重新接入家庭生活后真实获得的一段人生，而不是临时化名。

被带回家以后，Weston 家首先处理的是身体、安全和日常，而不是追问她的过去：

- 正常饮食和睡眠；
- 医疗检查与伤口处理；
- 允许独处，同时确保有人随时可找到；
- 不逼她立刻叫父母、兄姐或表现感激；
- 用固定日程、稳定回应和生活空间重新建立安全感。

一个多月里，她逐渐愿意说话、参与家庭生活、接受身体接触和日常安排。

之后她经历一次高烧，并恢复此前的童年记忆与平行世界记忆。

记忆恢复后，她没有因此否定 Weston 家。相反，她最终明确认定自己是 Alexis Weston，这种自我认同与归属感会成为后续眼睛由绿 / 金波动逐渐稳定为金色的重要前置。具体外貌机制见 `03_人物/外貌设定_亚历克西斯与伊莲娜.md`。

## 八、为什么选择家庭教育

Weston 家决定不立即把 Alexis 送进普通学校，主要原因是：

- 身体虚弱、伤疤和既往虐待仍需长期照顾；
- 她缺乏正常集体生活经验；
- 需要更可控、更安全的恢复环境；
- 她的学习速度很快，普通年级制很快无法匹配。

家庭教育不是“天才儿童跳过普通社会”的奖励，而是一开始出于恢复与保护做出的现实选择。

家里每个人都成为她的老师：

- Linda：文学、写作、阅读、叙事与社会观察；
- Vincent：艺术、摄影、设计、审美与视觉训练；
- Ilena / Roland：各自擅长的学科、运动、生活技能与同辈 / 年长手足式陪伴；
- Angelina：阅读习惯、家族生活、园艺 / 审美与长期积累式教育。

Alexis 因极高学习能力迅速完成小学、初中层级的大量内容，并广泛阅读。她的“有教养和有学识”不是十一岁进入 Hogwarts 后突然获得的，而是过去三四年家庭教育反复训练的结果。

因此一年级的她面对成年人的称呼、正式场合、用餐、来客、公开活动和媒体时，会比大多数同龄儿童更从容；但这种从容属于 Weston 家和个人经历塑造出来的现代上层 / 文化家庭社会化，不等于她已经掌握纯血巫师的旧家族社交编码。

## 九、Linda 的儿童作家事业与 Alexis 的公开经验

Linda 最初前往孤儿院正是为了创作取材。Alexis 进入家庭以后，她开始正式创作儿童作品，并在几年内事业迅速上升，成为畅销儿童书作家。

这里不要写成“Alexis 是灵感缪斯，所以 Linda 成功”。更合理的是：孤儿院经历、家庭结构变化和长期与三个孩子共同生活改变了 Linda 的创作方向，而她本身已有编剧与文学职业基础。

随着 Linda 的事业扩大，Alexis 会自然拥有一定抛头露面的经验：

- 新书发布、签售或出版社活动；
- 摄影、封面、访谈等家庭工作环境；
- 与编辑、记者、作家、艺术从业者接触；
- 正式宴会、展览、公益或文化活动。

因此她十一岁进入 Hogwarts 时不是第一次被陌生成年人观察，也不是第一次需要在公开场合维持礼仪。这一背景可直接支撑她“一眼看起来就不像未经社会化的普通十一岁新生”的外在气质。

## 十、第一部必须因此修改的原稿点

### 1. 家族关系

删除 / 改写旧稿中“Vincent 是 Ilena 母亲的弟弟，Clara 夫妇死后由舅舅收养双胞胎”的表述。

现行结构是：

**Angelina → Vincent / Clara 姐弟 → Clara 的双胞胎 Ilena / Roland；Vincent 与 Linda 在 Clara 夫妇去世后共同接回两个孩子。**

### 2. 姓氏逻辑

Ilena / Roland 保留 White 姓不是“还没来得及改”，而是整个家庭主动尊重他们与亲生父母的联系。此后也不需要通过改成 Weston 来证明亲密。

这应成为 Alexis 身份线的家庭先例：一个家庭可以承认多个姓氏、多个来源和真实共存的身份。

### 3. Harry 看到的 Weston 家

第一部中 Harry 与 Weston 家接触时，不应只得到“温暖养父母”这一印象。

他应该同时看到：

- 家庭成员彼此说话非常自然，能互相取笑；
- 文化、艺术和阅读是日常，而非展示身份的装饰；
- 家庭礼仪好，但不会用礼仪压迫孩子；
- Alexis 被认真照顾，也被当成有判断力的人；
- Ilena / Roland 姓 White，却没有任何人把他们视作“外人”。

这会让 Harry 第一次真正感受到：家庭可以不是“血缘一致 + 同一姓氏 + 成年人拥有绝对权力”才成立。

### 4. Hogwarts 入学前的 Alexis

她已经具备：

- 很高的知识密度；
- 正式场合经验；
- 家庭式安全感；
- 与成年人交流的基本自信；
- 对失去家庭的高度敏感；
- 在普通同龄社交上的经验不足。

因此她进入 Hogwarts 后的矛盾应是“有成人世界经验，却缺少真正长期的同龄集体生活”，而不是笼统地写成早熟。

## 十一、暂未决定 / 后续可继续讨论

以下内容暂不视为确认设定：

1. Clara 夫妇车祸是否存在幕后故事，以及幕后故事是否与魔法界有关。
2. Vincent / Linda 没有亲生孩子的具体生理原因。
3. Alex（Angelina 丈夫）的完整生平、职业与家族位置。
4. Vincent / Linda 在 Cambridge 相识的具体展览、年份与求爱过程细节。
5. Linda 早期编剧作品与后来儿童文学作品的具体书目。

这些项目在后续需要剧情功能时再展开，第一部重修不得提前用含混伏笔把它们写成已经存在的阴谋线。
