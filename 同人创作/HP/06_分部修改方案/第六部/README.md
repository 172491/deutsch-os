## 已确认的重构接口

1. 原“血液培养 + 持续位置 / 心率 + Draco 双向监控”的健康监测手表取消。关系修复改用危险行动前的信息协议、预计返回时间、紧急联系人和有限主动授权。
2. 战争压力不能让第五部已经建立的自主权规则失效：Harry、Draco、Snape、Sirius 不能重新只负责追赶 / 监管 Eleanor。
3. Eleanor 的高危灵魂 / Horcrux / 黑魔法研究继续受能力来源、反噬和团队边界约束；自毁不能换升级。
4. Fred / George 与 Shafiq 的技术网络已各自发展，不能自动作为 Eleanor 的后台资源。Alexis 的核心创造能力定位为“魔法系统工程与应用设计”，Shafiq 提供不可替代的工程化、量产、维护、合同与制度能力。
5. 第六部从现在起执行“章节融合、档案分追踪”：剧情、能力、关系与世界变化在章节里由同一事件共同推进；独立关系档案和能力档案继续用于连续性校验。
6. 原稿中 Eleanor 离校、秘密行动、恢复和开学后的独行节点均重新检查：她可以继续拥有主动性，但不能通过排除所有其他角色来维持主角推进。

## 第六部当前主轴

- 战争期团队与决策权；
- “活着像任务”的自我工具化极限；
- 成熟关系能否容纳秘密、拒绝、失联与不同立场；
- 技术与专业合作如何脱离个人控制并进入社会；
- “为什么还要活”从任务理由逐渐转向 Eleanor 自己的生活欲望。

后续剧情从开学初继续推进；Voldemort 在得知 Cup 失窃后究竟检查到多少 Horcrux、如何调整战略，是下一阶段需要先钉死的外部主线。
