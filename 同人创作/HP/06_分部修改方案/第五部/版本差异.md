# 第五部版本差异

## 当前读取规则

第五部不是简单“新版本全文覆盖旧版本”，而是逐层继承：

- **v1.0**：保留威士顿血案、成年人调查、能力边界、Gemma 地址泄漏暗线、神秘事务司大战等总体结构基础。
- **v1.1**：建立在 v1.0 上，重点重新校正 Eleanor — Harry、Eleanor — Draco、Harry — Draco 三条关系，把信息权、选择权、指挥权压回 36 章。
- **v1.2**：建立在 v1.1 上，重点重构 Horcrux 处置节奏、Draco 的中止权、Dumbledore 的成年责任与 Snape 的知情边界，并与第六部晚八月“检查 Ravenclaw's Diadem”暗线接轨。

处理第五部时：

1. **先读 v1.2** 的修改说明与重构大纲；
2. v1.2 未改写的章节继续读 v1.1；
3. v1.1 未重写的调查、能力与总体事件结构继续读 v1.0；
4. 同时读取当前人物关系总档案、2026-10-03 新增的 Weston、朋友群、Shafiq 关系档案与能力总档案；
5. 若版本文件与 `08_决策记录/已确认设定.md` 冲突，以已确认设定为最高优先级。

## v1.2 明确新增 / 强化

- 第13章找到 Ravenclaw's Diadem 后不立即销毁；Diadem 与 Gaunt Ring 都进入隔离、封存和共同处理流程；
- Eleanor 负责来源判断、灵魂结构与整体目标；Draco 负责诅咒、容器与风险判断，并拥有真实中止权；
- 第17章末第一次正式处理 Diadem 时，由 Draco 叫停，Eleanor 与 Dumbledore 都接受停止；
- 第18章初条件补足后，由 Eleanor、Draco、Dumbledore 三人按规则安全销毁 Diadem；
- Gaunt Ring 因独立附加诅咒继续封存；研究重点改为“怎样安全处理戒指诅咒”，而不是“怎样销毁 Horcrux”；
- 第24章只销毁 Ring。Dumbledore 明确要求等待，Eleanor 在评估阶段提前执行，Ring 被毁但左手中咒；
- Draco 不再把 Diadem 或 Ring 交还给 Eleanor；第24章的越权责任明确属于 Eleanor 本人；
- Snape 不进入“Diadem 是 Horcrux—藏在 Room of Requirement—已被销毁”的完整事实链；
- 因此第六部 Voldemort 命令 Snape 检查 Diadem 时，Snape 第一次从敌方获得这一具体 Horcrux 级信息。

## v1.1 明确新增 / 强化

- Harry 不再只是被保护者，要夺回参与、保护和决定自己风险的权利；
- Eleanor 不能继续用另一世界 Harry 样本替当前 Harry 作答；
- Draco 的伴侣权利包括反对、拒绝和独立判断，而非更高级的“监督权限”；
- Harry — Draco 必须形成不经过 Eleanor 中转的专业互认与战术信任；
- 神秘事务司前后必须明确谁拥有信息、选择和现场指挥权；
- Eleanor 失能后，其他人能够接管而不是等待她恢复。

## v1.0 继续有效的基础

除非与后续决策冲突，下列方向继续沿用：

- Weston 血案及其成年人调查结构；
- Gemma 相关暗线；
- 能力不能无限堆叠、自毁不能等于升级；
- 神秘事务司大战需要多人完成不可替代部分；
- Ministry / Umbridge / Phoenix / 家族等制度线。

## 2026-10-03 以后总档案对第五部的补充

- Weston 一家：血案必须结算“家庭生活、求助信念、身份稳定、未来想象”四层损失。
- 朋友群：Hermione、Ron、Ginny、Luna、Neville 不能只作为大战成员或 Eleanor 的情绪支持。
- Shafiq：资金、审判、产品撤回等必须写成家族独立判断，而不是 Eleanor 一句话调动势力。
- 技术：产品流向、停用、生产与查看权限本身就是关系和政治问题。
- 第五部 v1.2 人物关系增量另见：`04_人物关系/人物情感线总档案/当前版/补丁_第五部v1.2_魂器处置与知情边界.md`。
