# Eleanor 第五部 v1.2｜魂器处置与关系权力校正版

本版本建立在 v1.1《核心三关系深化版》之上，不推翻 v1.0 / v1.1 已成立的总体结构与36章顺序。

## 读取优先级

1. 先读本目录 `修改说明_魂器处置与关系权力校正版.md`；
2. 再读 `重构大纲_魂器处置与关系权力校正版.md`；
3. 本版未改写的章节继续沿用 v1.1；
4. v1.1 未覆盖的制度、调查、Weston 血案、Gemma 暗线、神秘事务司总体结构继续沿用 v1.0；
5. 若与 `08_决策记录/已确认设定.md` 冲突，以已确认设定为最高优先级。

## v1.2 核心修订

- 不再让拉文克劳冠冕与冈特戒指在第24章被连续、快速销毁；
- 第13章找到冠冕后，冠冕与戒指都先进入高危物品封存与共同处理流程；
- 第17章末—第18章初，Eleanor、Draco、Dumbledore 按已经建立的规则成功销毁冠冕；
- 冈特戒指因附加诅咒继续封存；
- 第24章只销毁戒指，并把事故改写为 Eleanor 明知规则有效却重新收回最终决定权的越权行为；
- Draco 不再把冠冕交还给 Eleanor，也不承担“明知危险仍把魂器递给她”的责任；
- Snape 不进入“冠冕身份—有求必应屋藏匿点—已被销毁”的完整知情链，为第六部 Voldemort 命令其检查冠冕保留真实信息增量；
- 魂器线正式服务于第五部“信息权—选择权—指挥权”的关系主轴，而不是作为单独的收集/销毁任务线。

## 本版与第六部接口

第六部晚八月 Voldemort 要求 Snape 进入有求必应屋确认 Ravenclaw's Diadem 是否仍在时：

- Dumbledore 已知冠冕被毁；
- Draco 已知并亲自参与过处理；
- Eleanor 已知；
- Snape 此前不知道完整事实，因此该命令第一次从 Voldemort 一侧把“冠冕”这一具体秘密交到他手中；
- Voldemort 发现 Cup 失窃后再发现 Diadem 不在，可形成第二个实质异常，但仍不足以让他立刻盘点全部 Horcrux。
