# 已确认设定

> 只记录已经明确成立、可跨卷约束后续写作的内容。历史讨论中的候选方案不自动进入本文件。

## A. 信息与平行世界历史

1. **平行世界历史不是“原著剧情”。** 对 Alexis / Eleanor 而言，那是另一个真实平行世界已经发生过的一段历史。
2. **信息严格受 Harry 七学年视角限制。** Harry 不知道的事，她不能因为“读者知道”而知道；毕业以后发生的事情也不在这套历史样本中。
3. **其他角色不得越权知道这套历史。** Ginny 等人只能依据自己亲历、被告知或调查获得的信息判断 Alexis / Eleanor。
4. **现实改变以后，历史样本不能被写成当前世界的全知预言。** 第二、三部的认知线正是她不断给模型加补丁、却越来越难保证可证伪性。

## B. 身份

1. **Alexis Weston 与 Eleanor Potter 都是真实的她。** “Alexis 是虚构身份，Eleanor 才是真的”不是叙事结论。
2. 身份公开应改变社会位置、家庭关系与政治含义，但不能抹掉 Weston 家庭和 Alexis 人生的真实性。

## C. 第二部 Ginny / 密室

1. Ginny 暑假并不知道 Alexis 是 Slytherin；真正的第一次关系破裂发生在开学火车上。
2. Alexis 因这次离开熟人包厢，随后才认识 Luna。
3. Ginny 不会把日记秘密完整告诉 Alexis，只会在有限信任形成后绕着症状提问。
4. Ginny 试图向 Harry / Ron / Hermione 求助被 Percy 偶然打断后，Alexis 没有把求助重新接回公共系统，而是选择自己接手；这是本卷关键的可归责选择。
5. 密室终局保留 Ginny 与 Alexis 一起失踪 / 被带入密室；Harry、Draco、Snape、Ginny、Fawkes 等必须各自完成不可替代部分，不能改成 Alexis 单人解决。
6. 善后不以一句道歉立即和好；Ginny 可以感谢救命，同时明确指出“活下来不等于你的风险判断正确”。

## D. 能力与发明

1. **Alexis / Eleanor 很强，但不是所有专业领域都比专业者更强。** 发明、Healing、Wolfsbane、Time-Turner、战斗等能力不能无限叠加成全能。
2. **发明能力核心调整为系统设计与整合。** Fred / George 提供原型、测试与自己的创造逻辑；Ravenclaw / 既有知识提供前人基础；Shafiq 技术网络承担工程化、稳定化、生产与部分专业魔咒补足。
3. **技术必须存在限制。** 通讯板、记录装置、防御类道具必须写明延迟、噪声、耗魔、存储、可信度、稳定性、被破坏/篡改等实际边界。
4. **自毁不能换升级。** 身体损耗、极端实验或受伤不能自动成为获得更强能力的兑换机制。

## E. 关系总原则

1. **关系必须改变选择；选择必须反过来改变剧情。** 甜蜜、争吵或陪伴本身不等于完成关系线。
2. **亲近不等于决策权。** 第五部三人结构的核心是信息权、选择权、指挥权，而不是谁更爱 Eleanor。
3. **Eleanor — Draco**：伴侣关系的成熟方向是双方都拥有反对和拒绝权；“爱你”不能成为替对方决定的理由。
4. **Eleanor — Harry**：从“我以为我了解你”走向重新认识当下 Harry，并接受双向保护；另一世界 Harry 的历史样本不能替现在的 Harry 作答。
5. **Harry — Draco**：不要求成为朋友；目标是从专业互认走向没有 Eleanor 在场也能进行关键合作。
6. **Eleanor — Snape**：老师 / 院长 / 长期导师在前，父职功能在后；不得用“父女”覆盖专业关系。
7. **Eleanor — Sirius**：核心不是反复结算“当年为什么弄丢我”，而是补偿欲、迟到家庭与 Eleanor 自主权的长期冲突。

## F. 第三部世界结构

1. 第三部不是简单增加 Ministry 场景，而是让 Hogwarts、Ministry、媒体、纯血家族、学生社会、Shafiq、第一次战争遗产等系统在 Alexis 不在场时也能行动。
2. Nott 等人的“替位”不能被宣布为神秘强制力的唯一答案；社会结构、同伴强化、父辈网络与个人欲望等可观察解释必须同时存在。
3. Buckbeak 线应作为课堂事故进入家长投诉、校董、委员会与合法程序的制度课，而不是单纯宠物支线。

## G. 第四、五部核心方向

1. 第四部必须让“失去未来确定性”真正改变 Alexis 的时间分配、求助方式、恋爱可能性和生活感；不是简单把她性格写软。
2. Draco 不是第四部突然变得值得爱；变化首先发生在 Alexis 是否允许爱情进入当下。
3. Weston 家不是死亡伏笔工具；第四部必须承担“如果没有战争，她本来可以怎样生活”的功能。
4. 第五部不能把三人关系收束成“Harry 和 Draco 都学会照顾 Eleanor”，而应写成 Eleanor 无法继续垄断最终决定权。
