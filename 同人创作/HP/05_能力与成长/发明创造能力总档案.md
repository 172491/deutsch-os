# Eleanor / Alexis 发明创造能力总档案

> 状态：已建立现行总框架。核心方向已经确认：她的优势不是“凭空发明一切”，而是系统设计、跨领域整合、快速学习与把不同人的专业能力组合成可用系统。

## 一、能力定义

Eleanor / Alexis 的发明能力主要由五部分构成：

1. **需求识别**：能迅速发现现实行动中的信息、保护、证据或操作缺口。
2. **系统架构**：擅长把多个已有魔法、材料、如尼文、道具机制组织成一个整体。
3. **跨领域迁移**：会把麻瓜世界的工程 / 信息 / 实验思维迁移到魔法道具问题中，但不等于她掌握全部专业技术。
4. **高强度迭代**：能够大量阅读、做实验、记录失败、快速修改原型。
5. **风险模型**：习惯提前想失败模式与备用方案；这是优势，也是她“以为复杂模型可以控制世界”的人格风险来源。

她不是：全领域理论首创者、所有专业魔咒的最佳施术者、成熟工厂、法规专家、供应链、测试团队和商业网络的集合体。

## 四、能力硬边界

1. **架构 ≠ 工程化。** 能构想出系统不等于能稳定制造上百件可重复产品。
2. **原型成功 ≠ 可部署。** 必须经过极端条件、误操作、持续时间、耗魔和破坏测试。
3. **信息更多 ≠ 判断正确。** 通讯、记录和传感设备只增加输入，不自动解决认知偏差。
4. **私人信任 ≠ 技术权限。** 恋人、朋友、家人不因亲密自动获得持续定位、健康数据、单方面停用或后台查看权。
5. **战争紧急 ≠ 永久监控。** 紧急模式必须与日常权限分开。
6. **学习快 ≠ 专业资质。** 她可以理解专业者的工作并协作，但不因为几个月研究就全面超过 Pomfrey、成熟治疗师、Shafiq 工程团队或专门研究者。

## 五、未来每个发明项目的最低记录字段

后续新项目必须明确：

- 解决的具体问题；
- 首个原型是谁提出 / 完成；
- Eleanor / Alexis 的核心贡献；
- 其他参与者的不可替代贡献；
- 已知失败模式；
- 耗魔 / 材料 / 时间成本；
- 谁能使用、谁能查看信息、谁能停用；
- 是否可规模生产；
- 流向、合同与政治风险；
- 项目如何改变至少一条人物关系。
