# 能力与成长

本目录不做“技能清单”，而是追踪能力如何形成、由谁补足、在哪里失败，以及它如何改变人物关系与剧情选择。

- `发明创造能力总档案.md`：定义 Eleanor / Alexis 的发明优势、协作结构与跨卷发展。
- `魔法能力边界总表.md`：防止多个强项叠加成无边界全能。
- `治疗能力发展.md`：治疗学习的成长路径与专业边界。
- `项目档案/通讯板.md`：通讯系统的需求、协作者、限制与跨卷用途。
- `项目档案/记录装置.md`：第三部证据链相关的记录技术。
- `项目档案/防御纳特.md`：原稿已有项目的重构定位。
- `项目档案/后续项目.md`：尚未定型的战争期装置需求，包括已否决“健康监测手表”后的替代约束。

## 当前能力主原则

1. Eleanor / Alexis 可以拥有很高上限，但必须拆开魔力量、控制、技巧、知识、经验、身体承载与异常外来力量。
2. 她自身的自然成年魔力量大致在 James / Lily / 成年 Harry 的高水平区间；四年级属于提前成熟，不是自然上限无限抬高。
3. 四年级后的额外异常增长，需要区分 Voldemort 灵魂碎片、Horcrux诅咒转化与 Firenze 治疗所引入的外来魔力。
4. 无声 / 无杖施法按具体咒语熟练度判断。强化咒等魁地奇高频专项可以提前高度自动化，但不能据此推导为普遍无声无杖。
5. 高魔力量不等于成年级实战经验，也不等于所有专业领域自动领先。
6. 自毁不能换升级；Horcrux诅咒的吸收与转化属于高风险治疗与异常魔力状态，不能写成“受伤就变强”。
7. Firenze 在五年级末至六年级主要负责增强灵魂、稳定魔力、转化诅咒和保命；Harry / Eleanor体内的Voldemort灵魂碎片至少要等Voldemort死亡后再进行真正剥离。
8. 四年级末“Eleanor杀死两名Death Eater”的旧情节删除，不再作为能力成长依据。

## 使用规则

1. 每个能力项目至少写明：核心需求、Eleanor / Alexis 自己的贡献、别人不可替代的贡献、失败条件、使用代价、流向 / 权限。
2. 技术成功不能自动证明人物判断正确。
3. 自毁不能换升级；受伤不能代替训练、工程验证或关系后果。
4. 能力线发生变化时同步检查 `04_人物关系/` 与 `02_总体结构/跨卷连续性总表.md`。
