# 能力与成长

本目录不做“技能清单”，而是追踪能力如何形成、由谁补足、在哪里失败，以及它如何改变人物关系与剧情选择。

## 当前文件

- `发明创造能力总档案.md`：定义 Eleanor / Alexis 的发明优势、协作结构与跨卷发展。
- `魔法能力边界总表.md`：防止多个强项叠加成无边界全能。
- `治疗能力发展.md`：治疗学习的成长路径与专业边界。
- `项目档案/通讯板.md`：通讯系统的需求、协作者、限制与跨卷用途。
- `项目档案/记录装置.md`：第三部证据链相关的记录技术。
- `项目档案/防御纳特.md`：原稿已有项目的重构定位。
- `项目档案/后续项目.md`：尚未定型的战争期装置需求，包括已否决“健康监测手表”后的替代约束。

## 使用规则

1. 每个能力项目至少写明：核心需求、Eleanor / Alexis 自己的贡献、别人不可替代的贡献、失败条件、使用代价、流向 / 权限。
2. 技术成功不能自动证明人物判断正确。
3. 自毁不能换升级；受伤不能代替训练、工程验证或关系后果。
4. 能力线发生变化时同步检查 `04_人物关系/` 与 `02_总体结构/跨卷连续性总表.md`。
