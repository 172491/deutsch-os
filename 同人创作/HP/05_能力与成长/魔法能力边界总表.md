# 魔法能力边界总表

> 目的：保留 Eleanor / Alexis 的高天赋与高学习速度，同时防止发明、战斗、治疗、魔药、精神魔法等同时无边界升级。  
> 魔力与战斗的详细当前版以 `魔力底盘与战斗能力总档案.md` 为准。

| 领域 | 她可以很强的部分 | 必须保留的边界 | 主要专业参照 / 补足者 | 禁止的快捷写法 |
| --- | --- | --- | --- | --- |
| 基础魔力 / 施法 | 天生魔力强、成长快、控制精细；四年级可提前达到自身成年级自然魔力量；少数高频专项可高度自动化 | 自身自然成年上限约在 James / Lily / 成年 Harry 的高水平区间；四年级后的异常增量要区分 Voldemort碎片、Horcrux与Firenze治疗；魔力量不等于技巧、经验和专业知识 | Snape、Dumbledore、成熟成年巫师 | “魔力大所以所有咒语都更强 / 都能无声无杖” |
| 学习 / 记忆 | 高速阅读、优秀记忆、跨学科联系、长期整理信息 | 平行世界历史有 Harry 视角边界；信息完整度和判断正确率不是一回事 | Hermione 的学术方法、教师、现实调查 | “记得多所以一定判断对” |
| 无声 / 无杖 | 对长期高频使用的专项咒语，可较早形成无声甚至无杖自动化；强化咒是典型 | 必须逐咒判断练习量、使用频率、复杂度与稳定性；三年级能无声无杖强化咒不等于普遍无声无杖 | 教师、长期实战与训练 | 按年级一次性解锁“全部无声”“全部无杖” |
| 战斗 | 反应快、学习新咒快、控制力高、能组合多种魔法，擅长场地控制、信息差与战术整合 | 体力、经验、人数、地形、意外、黑魔法知识差距仍有效；成年级魔力量不等于成年级实战经验 | Snape、成年战斗者、Harry 的临场能力、团队 | 每次升级靠学到更强咒语单刷高潮；用四年级旧版“两名Death Eater击杀”证明成熟杀人能力 |
| 魔药 | 学术能力高、实验严谨、能理解配方机制 | 高级魔药仍受经验、材料、时间与专业训练约束 | Snape、成熟魔药师 | 一次读书就超过长期专业者 |
| 治疗 | 能学急救、基础 / 中阶治疗、状态判断、协助医疗 | 复杂创伤、诅咒、长期治疗、诊断和康复必须依赖专业体系 | Pomfrey、St Mungo、Jacob 等 | “她自己会治，所以受伤没有现实代价” |
| 精神魔法 | 大脑封闭术等可成为重要训练方向 | 创伤、疲劳、信息洪流和更强施术者仍能造成失败；精神魔法不是读心真相机 | Snape、Dumbledore 等 | 用摄神取念解决所有信息冲突 |
| 发明 / 如尼 / 装置 | 系统架构、跨领域整合、原型设计、实验迭代 | 工程化、稳定性、制造、专业识别魔咒、供应链必须由多人完成 | Fred / George、Shafiq 技术网络、既有文献 | “她独自闭关几天造出革命性成品” |
| 魁地奇 / 飞行 | 技巧性强、战术学习快、找球手天赋；能把强化咒等高频魔法融入运动技术 | 体能、心肺、骨骼与韧带承载、天气、伤病、球队配合仍是现实变量；持续强化消耗魔力 | 队友、Cedric 等高水平选手 | 魔法天赋自动等于体育无短板 |
| 时间转换器使用 | 能执行复杂时间表、理解风险 | 时间不是免费资源；疲劳、认知负荷、重复行动风险不可消失 | Hermione 的使用经验、McGonagall / 制度授权 | 把时间转换器当无限学习时长作弊器 |
| 灵魂 / Horcrux / 高危黑魔法 | 可以因战争需要研究并形成特殊知识积累；后期可出现异常魔力峰值 | Horcrux诅咒吞噬生命力；Firenze治疗属于高风险保命与转化，不是常规升级；魔力透支在治疗期可能致命；灵魂碎片真正剥离至少在Voldemort死亡后 | Firenze、Dumbledore、Snape、历史资料、团队 | “吸收诅咒所以获得抗性并永久无代价升级” |
| 社会 / 政治判断 | 擅长建模、谈判准备、把技术和利益联系起来 | 她不是天然政治家；家族、Ministry、媒体都有不可控目标 | Jacob、Dumbledore、成年人、不同家族 | “她算到了所有人的反应” |

## 总体检查

当某一章同时让她在三个以上专业领域压倒专业人士时，必须重新检查：

- 这一章真正需要的是她的哪一项核心能力？
- 其他结果能否由团队分工完成？
- 是否把“系统整合能力”误写成“所有子系统都由她本人专业领先”？
- 是否把“魔力总量”误写成“技巧、知识、经验和身体承载同步无条件增长”？
