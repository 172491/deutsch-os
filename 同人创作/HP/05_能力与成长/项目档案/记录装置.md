# 项目档案｜记录装置

> 状态：第三部现行修改方向。它服务于“如何把私人真相变成公共事实”，而不是提供绝对真相。

## 1. 叙事功能

第三部 Sirius 案等问题要求 Eleanor / Alexis 面对一个新层级：她自己知道真相没有用，必须让证据进入别人可接受的制度链。

记录装置因此承担：

- 提前保存现场信息；
- 为证人证词提供辅助；
- 在不同叙事之间增加可验证材料；
- 让“证据如何被相信”成为剧情问题。

## 2. 必须提前建立的限制

- 存储容量有限；
- 长时间记录的稳定性下降；
- 记录范围、角度或感知维度有限；
- 设备可以损坏；
- 记录可能被质疑剪辑、篡改或施咒；
- “装置记录了”不等于 Ministry / 媒体 /公众自动承认；
- 必须有见证人、成年权威、程序和舆论压力共同形成可信度。

## 3. 技术与证据分工

Eleanor 可以参与设计和部署，但证据链必须由多人共同完成：

- 现场人物提供证词；
- 装置提供有限记录；
- Dumbledore / 其他成年人承担制度转化；
- 媒体决定如何传播；
- Ministry 决定承认、拖延或攻击证据。

## 4. 关系与认知作用

记录装置是她“更多信息就能控制结果”思路的一次升级，但第三部必须让她发现：

**信息的存在、信息的可信、信息的传播、信息产生政治后果，是四件不同的事。**
