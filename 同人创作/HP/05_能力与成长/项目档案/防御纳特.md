# 项目档案｜防御纳特 / 多功能防御原型

> 状态：原稿已有较完整项目，重构保留“学生原型 → Shafiq 工程化 → 产品流向产生政治后果”的方向，但具体性能参数需要重新审核，不能直接沿用旧稿的强度数字。

## 1. 原稿核心概念

以普通铜纳特等低可见度物件作为载体，通过魔力驱动形成局部防御 / 防窃听等功能，并尝试加入身份识别、魔力放大和多场景保护。

这个方向有价值，因为它天然连接三条线：

- Eleanor / Alexis 的系统整合能力；
- Fred / George 等人的原型创造；
- Shafiq 的工程、制造、合同与战争资源网络。

## 2. 重构后必须拆开的层级

### 原型层

学生可以做出有效但不稳定的原型，明确知道某些测试结果。

### 工程层

Shafiq 技术人员需要解决：

- 批次一致性；
- 材料耐久；
- 误触发；
- 身份识别；
- 极端黑魔法下的失效模式；
- 使用说明与训练；
- 质量检测。

### 部署层

谁拿到产品、谁付钱、谁能回收、是否提供 Ministry / Phoenix /普通家庭，是政治选择，不是发明人的附带决定。

## 3. 不能沿用的写法

- 用少量学生实验直接证明可以抵抗任何高级黑魔法；
- 用从高空跳下等自伤测试制造“天才可信度”；
- Alexis 给出完整战争商业战略，Jacob / 家族只负责点头；
- 产品一投入使用就没有误报、滥用、黑市和对手适应问题。

## 4. 与 Shafiq 关系的关键节点

真正重要的不是“她把一个厉害发明卖给 Shafiq”，而是：

1. 她必须交出一部分控制权，让专业团队修改自己的设计；
2. Jacob 必须能够质疑性能、拒绝流向或要求重新测试；
3. 她的战争目标与 Shafiq 的家族长期利益可能重合，也可能不重合；
4. 合作能继续，是因为双方反复证明有价值且守规则，而不是一次人情。
