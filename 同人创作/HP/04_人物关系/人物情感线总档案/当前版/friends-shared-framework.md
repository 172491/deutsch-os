# Hermione / Ron / Ginny / Luna / Neville｜共享关系框架

> “朋友群”不是一条关系。五个人与 Eleanor / Alexis 的信息量、价值冲突、相处方式和能改变她的部分都不同。这个文件只保存共享边界，不替代五条独立关系。

## 一、五个人分别知道什么

| 人物 | 可以知道 / 观察 | 不能默认知道 |
| --- | --- | --- |
| Hermione | 学校内大量现实事实、共同课程与学习状态、Alexis 公开的伤势和关系、Alexis 主动告诉她的私人内容 | 平行世界历史、未被告知的创伤细节、Time-Turner 私下滥用次数、每次行动的真实目的与完整战争计划 |
| Ron | 巫师家庭 / 纯血社会常识、校园关系、Weasley 家信息 | Alexis 的隐秘认知模型和全部技术 / 战争计划 |
| Ginny | 自己与 Alexis 的二年级经历、她曾隐瞒 / 接管求助的事实 | 平行世界历史；Alexis 为什么提前知道日记轮廓 |
| Luna | 自己观察到的异常、非主流信息源、朋友之间的现实互动 | “因为她特别所以天然知道真相” |
| Neville | 自己与她的学校经历、公开战争信息 | 她早年如何根据另一世界历史判断他的事件 |

## 二、朋友群不是固定五人小队

这些人可以在不同阶段交叉成为朋友，但不要为了“群像”强行让所有人同时行动。真正的群像标准是：

- Eleanor 不在场时，他们之间仍有关系；
- 他们会互相选择、争吵、合作；
- 他们拥有 Eleanor 不知道的经历；
- Eleanor 的错误不会让所有人得出同一个结论；
- 他们各自的成长不会以“更理解 Eleanor”为终点。

## 三、群像施工原则

任何人都不能因为“聪明”“亲近”“被救过”而获得作者视角。关系深化必须由真实共同事件、可见行为和实际信息渠道支撑。尤其不要把 Hermione 变成心理分析师、Luna 变成预言机、Ginny 变成永久的小妹妹、Ron 变成笑点、Neville 变成成长教材。
