# 第八章｜Eleanor / Alexis × Jacob Shafiq / Shafiq 家族

> *这条关系的核心不是“Alexis 找到了一个有钱有技术的纯血家族”，而是她第一次进入一个真正会谈条件、会修改她的设计、也有资格拒绝她的专业网络。Jacob 既是朋友和高年级学长，也是未来家族决策者；这几种身份不能被压缩成资源提供者。*

# 一、关系定位

| 层级 | 内容 | 边界 |
| --- | --- | --- |
| 高年级同学 / 学长 | Jacob 比 Alexis 年长，最早因她的学习与能力注意到她 | 不是老师，也不是“成熟成年人替她兜底” |
| Slytherin 内部关系 | 在学院政治中能提供真实支持与社会信号 | 不能因为 Jacob 支持，Alexis 就没有学院孤立成本 |
| 专业朋友 | 两人能谈治疗、研究、技术与未来规划 | 朋友不等于所有方案都赞成 |
| 商业 / 技术合作方 | Shafiq 提供工程、生产、合同与家族网络 | 必须拥有谈判、拒绝、延期和修改权 |
| 政治关系接口 | 家族有自己的 Ministry、纯血社会和战时利益 | 不受 Alexis 一句话遥控 |

# 二、一年级：关系起点应该是专业兴趣，而不是资源交换

现有原稿回顾写明：Jacob 首先是在图书馆 / 学习环境中注意到疯狂阅读的 Alexis；两人因为对麻瓜思想、魔法知识和学习的开放态度逐渐成为朋友。

这个起点很重要。若一开始就让 Alexis 因“Shafiq 有钱有技术”主动经营关系，这条线会变得过度功利。更合理的基础是：

- Jacob 先认识她这个人和她的工作方式；
- Alexis 逐渐知道 Shafiq 家族能做什么；
- 后来的合同建立在已有信誉上，而不是一次商业投机。

# 三、二年级：支持必须有分量，也必须有限

二年级 Alexis 因 Draco、Mudblood 事件和密室环境在 Slytherin 承受真实孤立。原稿中 Jacob 是少数明确支持 / 探望她的 Slytherin 高年级学生之一，同时还展示了比她更成熟的治疗魔法。

这有三个作用：

1. Jacob 的支持不是“全院都其实喜欢她”的证明，反而因为稀少才有分量；
2. Alexis 看到一个明确专业领域比自己强的人，帮助建立能力边界；
3. 通讯板等项目开始从“学生玩具”转向“可以交给专业技术人员继续完善”的真正合作。

# 四、三年级：从朋友变成谈判方

三年级是关系真正升级的阶段。原稿已经存在：

- Alexis 计划将通讯板 / 后续项目交给 Shafiq；
- 她与 Fred / George 的研究需要通过 Jacob 接入家族技术网络；
- 防御纳特等产品开始涉及工程、商业和战争流向；
- Jacob 同时承担级长 / 学院身份，不只是私人朋友。

重构后必须把这一步写成“控制权开始分散”：

**Alexis 能定义需求并提出架构，但当项目进入 Shafiq 网络后，Jacob 和技术团队必须能够说：这个参数不可信、这个测试不够、这个功能不能生产、这个合同条件我们不接受。**

如果合作从不出现这种真实摩擦，就还不是合作，只是资源调用。

# 五、能力线与关系线如何互相改变

| 技术节点 | 关系变化 |
| --- | --- |
| Alexis 第一次把未完成原型交出去 | 她承认别人可以改她的方案 |
| Shafiq 技术人员发现原型缺陷 | Jacob 不再只是“支持者”，而成为能提出不舒服事实的人 |
| Fred / George 的贡献进入产品 | Jacob 必须面对多方署名 / 利益，而不是只和 Alexis 一个人交易 |
| 产品开始产生收入 | 友情与合同必须分开；信任不等于不写规则 |
| 产品进入 Ministry /战争资源 | Jacob 的家族责任与 Alexis 的战争目标可能发生分歧 |
| Eleanor 要求撤回 /改变流向 | 必须通过既有权利、合同或重新谈判，而不是“她发明的所以她说了算” |

# 六、四年级：家族政治不能被恋爱线和 Triwizard 吞掉

第四部原稿中 Jacob 已经成为更明显的学院 / 家族接口，并通过信件、商业协议和政治信息与 Alexis 联系。

这一阶段应强调：

- Jacob 逐步接近正式家族责任；
- Alexis 失去平行世界确定性以后，仍能根据现实证据与他谈技术和政策，说明她的专业能力不是预知附属品；
- Shafiq 的“中立 / 倾向”必须是家族长期利益判断，不是因为喜欢 Alexis 就自动站队；
- Draco 对 Jacob 的竞争 / 警惕可以存在，但不能把 Jacob 降成恋爱竞争者。

# 七、第五部：真正的政治盟友必须有自己的成本

原稿中 Shafiq 已经能够影响 Ministry 资金关系、审判环境和产品流向。重构必须把这些作用从“Eleanor 背后势力很强”改成可理解的家族行为：

- 为什么 Shafiq 选择撤回或暂停某些合作？
- 他们损失什么，又避免什么风险？
- 与 Malfoy、Fudge、Bones、Dumbledore 的关系如何受影响？
- Eleanor 的建议只是输入之一，Jacob /家族依据什么独立作出决定？

Shafiq 的政治行动越重要，越不能只写一句“Jacob 会懂的”。

# 八、第六部：当前必须保留的空白

原稿第六部中 Shafiq / Jacob 的直接存在感下降。重构时不要机械把他重新塞回每个技术项目，而应先决定：

- 战争升级后 Shafiq 是公开盟友、有限技术合作方还是保持更深层的政治弹性？
- Fred / George 已经形成自己的商业与技术网络后，两套体系如何分工？
- Eleanor 个人脱离学校、频繁秘密行动后，Jacob 是否仍愿意为她承担高风险项目？

这些目前待后续第六部方案决定。

# 九、这条关系的长期成熟方向

最理想的变化不是“Jacob 越来越愿意帮她”，而是：

**从一个欣赏她能力、愿意支持她的学长，变成一个她真正愿意交出部分控制权、并且知道对方可能拒绝自己的合作伙伴。**

反过来，Jacob 也不能把她只视为天才设计来源。他必须逐渐承认：

- 她对战争风险的判断有独特价值；
- 她同时存在严重的过度控制和自毁倾向；
- 有时候最专业的合作不是替她把危险方案做得更稳定，而是拒绝继续做。

# 十、施工禁区

- Jacob / Shafiq = 钱 + 技术员 + 政治人脉。
- 所有合作都无条件成功。
- Alexis 一个人拥有全部知识产权和决定权，Fred / George 等人的贡献消失。
- 家族“中立”只是为了让他们随时站在正确一边。
- Draco 因恋爱天然比 Jacob 更有资格参与专业决策。
- Jacob 因年长几岁就变成父兄式管教者。
