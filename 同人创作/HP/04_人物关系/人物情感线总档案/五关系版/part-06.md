# 第八章｜Eleanor / Alexis × Jacob Shafiq / Shafiq 家族

> *这条关系的核心不是“Alexis 找到了一个有钱有技术的纯血家族”，而是她第一次进入一个真正会谈条件、会修改她的设计、也有资格拒绝她的专业网络。Jacob 既是朋友和高年级学长，也是未来家族决策者；这几种身份不能被压缩成资源提供者。*

# 一、关系定位

| 层级 | 内容 | 边界 |
| --- | --- | --- |
| 高年级同学 / 学长 | Jacob 比 Alexis 年长，最早因她的学习与能力注意到她 | 不是老师，也不是“成熟成年人替她兜底” |
| Slytherin 内部关系 | 在学院政治中能提供真实支持与社会信号 | 不能因为 Jacob 支持，Alexis 就没有学院孤立成本 |
| 专业朋友 | 两人能谈治疗、研究、技术与未来规划 | 朋友不等于所有方案都赞成 |
| 商业 / 技术合作方 | Shafiq 提供工程、生产、合同与家族网络 | 必须拥有谈判、拒绝、延期和修改权 |
| 政治关系接口 | 家族有自己的 Ministry、纯血社会和战时利益 | 不受 Alexis 一句话遥控 |

这条关系从现在起不再与 Alexis 的发明能力分开记录。技术升级、关系升级、社会位置变化和剧情后果必须由同一批事件推动。Jacob 不是站在“能力线”旁边提供资源的人，而是直接参与塑造 Alexis 怎样理解合作、专业权威、控制权和长期责任的人。

# 二、Alexis 的发明能力定位与 Shafiq 的不可替代性

当前确认：Alexis 最突出的创造能力是**魔法系统工程与应用设计**。她擅长把已有魔法拆解、重新组合、模块化，将高度个人化的魔法技巧转化成可以重复使用的工具和系统。她的强项在结构、接口、需求判断和魔法兼容性，不在基础魔法理论、材料工艺、独立量产或所有专业领域的全面领先。

她可以做出高水平原型，却无法一个人把原型变成社会产品。Shafiq 真正提供的是她个人不可能拥有的工程体系：材料与工艺专家、附魔工坊、批量测试、故障统计、成本控制、维护体系、合同、销售、法律和政治接口。Alexis 解决“这个问题能不能这样做”，Shafiq 必须继续回答“它能不能被一百个人稳定使用”“坏了由谁修”“谁拥有控制权”“政府要求数据时怎么办”“十年以后还要不要继续运行”。

因此，技术成果不是“Alexis 发明、Shafiq 量产”的单向关系。进入 Shafiq 网络以后，技术本身已经成为共同创造物，Jacob 和技术团队拥有真正修改、否决和延期的权利。

# 三、一至二年级：被看见，以及第一次交出未完成的东西

Jacob 最早应先认识 Alexis 这个人，而不是先认识她的商业价值。他在图书馆、学院生活和学习环境里注意到这个读书近乎疯狂、明显与同龄人不太一样的一年级生；二年级 Alexis 在 Slytherin 内部因 Draco、Mudblood 事件和密室环境承受孤立时，Jacob 的支持才因此具有分量。

这一阶段最重要的关系变化，是 Alexis 第一次把一个**没有完成、甚至可能失败的原型**给 Jacob 看。她平常更习惯展示结果，不喜欢别人进入自己无法控制的中间状态。粗糙的传讯原型因此不仅是能力节点，也是信任节点。

Jacob 的回应不能只是夸她聪明。他会认真问她不舒服的问题：为什么设备必须储存她本人的魔力；如果做五十台，她是不是准备给五十台分别补魔力；换一个使用者要不要重新绑定；设备坏掉以后谁负责；魔力来源不同会不会干扰结构。Alexis 可能先觉得他在忽视自己已经解决的难题，随后才意识到，Jacob 正因为把她当真正的研究者，才会认真挑毛病。

从这里开始，Jacob 不再只是“愿意保护她的学长”。他成为第一个能对她明确说“这个方案不行”，而关系不会因此断裂的人。

# 四、三年级：共同研发取代“天才 + 资源”的模式

三年级是关系真正升级的阶段。通讯技术和其他原型进入 Shafiq 工坊以后，Alexis 会第一次系统地发现自己的知识边界。她可能能画出漂亮的结构，却发现批量刻制后故障率失控；她认为最合适的材料可能贵到产品根本卖不出去；她认为“不太可能发生”的失误，会在测试中被普通使用者当天做出来。

这些失败必须进入剧情，因为它们同时改变能力和关系。Alexis 开始承认 Jacob 带来的不是“她懒得处理的杂务”，而是她真正不知道的专业知识；Jacob 也开始改变对她的态度，不再替她过滤所有商业和技术问题，而是把合同、成本表、技术团队的反对意见直接交给她，让她自己面对。

这里可以出现关系上很关键的一幕：Shafiq 的专业人员公开否定 Alexis 的某个方案，Jacob 不替她说话。他让她自己解释、修改或者承认失败。对 Alexis 来说，这是一种比“被保护”更高等级的尊重——平等意味着别人不会把她从冲突里抱走。

技术上的阶段也同步推进：二年级只做到预先绑定设备之间的短文字同步，语音实验可以存在但高度失真、噪声严重、稳定性差，视讯和成熟录音功能删除。三年级重点转向“怎样让设备不必固定一对一绑定”，由此开始出现地址、身份标记、中继和安全问题。每一个技术问题都会继续扩大 Jacob 与 Shafiq 在这条线中的作用。

# 五、四年级：记忆断裂之后，专业连续性证明“Alexis 仍然是 Alexis”

四年级 Alexis 失去平行世界相关记忆以后，技术合作仍然能够继续，这一点对两人的关系意义很大。她忘掉另一段历史，却没有忘记学过的如尼文、结构思维、研究习惯和与 Jacob 几年磨合出来的工作方式。她仍然能看故障报告、和技术人员争论、修改方案，也仍然会因为某个参数和 Jacob 吵上一场。

对 Jacob 来说，这会成为理解她身份的一种非常朴素的连续性：外界可以重新解释“Alexis Weston 原来也是 Eleanor Potter”，他却不需要把过去几年全部推翻。他认识的那个人仍然会坐在同一张桌子前，对第三号节点的失败率发脾气。

这也使 Jacob 成为 Weston 身份连续性的重要见证人之一。他认识她，不依赖 Potter 这个名字，也不依赖她掌握另一段历史。

第四部的通信项目可以在这一阶段第一次进入有限商业化：第一代产品以异步短文字为核心，有固定地址、维护要求和明确的结界限制，远未发展成魔法手机。强防护区域可能失效，霍格沃茨需要特定许可或节点，实时语音仍然昂贵且不稳定。产品进入社会后，Jacob 与 Alexis 的讨论也开始从“技术能不能做”变成“谁能使用、谁负责维护、谁有权管理”。

# 六、五年级：真正平等的伙伴开始拥有真实分歧

战争和 Ministry 压力把技术推入政治领域以后，两人的关系才真正成年。Alexis 会越来越倾向于把技术理解为战争资源：防御产品、通信网络、生产能力都可以为 Dumbledore、Phoenix Order 或对抗 Voldemort 服务。Jacob 未必反对战争合作，但他会坚持追问这套系统战争结束以后怎么办。

这会形成很适合两人的核心分歧。Alexis 很容易认为“Dumbledore 和 Fudge 当然不一样，因此可以给前者特殊权限”；Jacob 则必须从未来家主和基础设施经营者的角度提醒她：**制度不能靠你相信谁来设计。**如果今天因为信任某个人而留下后门，下一任掌权者也可以要求同样的权力。

反过来，Alexis 也会逼 Jacob 面对 Shafiq 自己的控制欲。若这套通信体系已经成为重要社会基础设施，家族产权同样不能无限扩张。谁控制中继、谁掌握元数据、政府能不能要求查询、用户有没有退出和匿名的权利，这些问题使两个人第一次不只是“朋友之间讨论方案”，而是在不同责任位置上发生真实利益冲突。

关系成熟因此不表现为 Jacob 越来越愿意帮她，而表现为他们能够在不同立场上争论，甚至暂时拒绝对方，同时继续合作。

# 七、能力线与关系线的同步节点

| 技术 / 能力节点 | 关系变化 | 剧情意义 |
| --- | --- | --- |
| Alexis 第一次把未完成原型交给 Jacob | 她允许别人进入自己的不确定和失败 | 信任第一次不以“我已经做好了”为前提 |
| Jacob / 技术人员指出原型不能量产 | Jacob 从支持者变成能否定她判断的人 | Alexis 开始学习专业合作而非资源调用 |
| 项目进入 Shafiq 工坊 | 两人第一次形成真实相互依赖 | 技术离开个人实验，进入社会系统 |
| Fred / George 等人的贡献进入产品 | Jacob 必须处理多方署名、利益与权利 | 发明线进入群像，不再归属于 Eleanor 一人 |
| 产品开始盈利和商业化 | 友情与合同分开，信任仍需制度约束 | Alexis 获得现实资源，同时失去单方面控制 |
| 通信 / 防御产品进入 Ministry 与战争 | 两人第一次产生原则性分歧 | 家族利益、公共基础设施与战争目标碰撞 |
| 技术能够在 Alexis 缺席时继续运行 | 她第一次看到系统不需要创造者也能活 | 为第六部失踪与毕业节点做准备 |

# 八、第六部：技术脱离创造者，关系也脱离学校环境

第六部必须把 Jacob 的毕业与 Alexis 的失踪放在同一条线上理解。她六月离校后去完成雷古勒斯、古灵阁和金杯行动，随后被囚。与此同时，Shafiq 的工坊、技术人员、合同和已经运行的项目不会因为 Alexis 不见了就停摆。Jacob 也不会因为她失踪就停止毕业、学生会职责和进入家族工作的进程。

这会让 Alexis 同时面对两件过去很少真正面对的事实：她创造的系统可以没有她继续运行；她珍视的人也会在没有她的时候继续生活。技术成熟与关系成熟在这里形成同一个结论——真正成熟的创造不能永远依赖创造者，真正成熟的关系也不能要求对方永远围绕自己停在原地。

Jacob 的毕业舞会因此具有比“错过一场舞”更深的意义。他很少向 Alexis 提出纯私人要求，毕业舞伴可以是一次明确的“那天我希望你在”。她答应，却没有出现。Jacob 会正常完成毕业、致辞、社交和告别，不把自己的毕业变成等待她的仪式；但那个缺席真实存在。他可以给她留下一个很简单的结论：约定没有因为她有更宏大的理由就自动消失，关系也没有因为她伤害了它就自动死亡。

“你的舞还欠着”因此同时代表两件事：我介意你没有来；我没有替你宣布这段关系结束。以后是否继续，需要两个人在离开霍格沃茨之后主动选择。

等 Alexis 回来以后，她会发现 Jacob 已经不在学校，Shafiq 的项目也没有停在她离开的那一天。这个经验直接击中她长期存在的控制幻觉：世界不会因为她暂时缺席而冻结，而这并不意味着她不重要。

# 九、关系的长期成熟方向

这条关系可以概括成五个连续阶段：

**被看见 → 允许别人进入自己的未完成状态 → 真正共同研发 → 成为可以发生原则性争论的平等伙伴 → 接受彼此拥有独立于这段关系之外的人生。**

技术线与之同步：

**个人实验 → 原型 → Shafiq 共同研发 → 社会产品 / 基础设施 → 脱离创造者继续运行。**

这两条不能在正文中拆开。每一次技术升级都应改变两人的信任、权利或责任；每一次关系升级也应改变他们之后怎样合作、怎样分享信息、怎样分配控制权。

Jacob 最终给予 Alexis 的经验不是无条件支持，而是让她逐渐接受：别人可以修改她的方案、拒绝她的请求、拥有自己的判断和生活，却仍然选择与她保持关系。Alexis 反过来也迫使 Jacob 从家族继承人的位置重新理解技术公共性、个人权利和制度边界。

# 十、施工禁区

- Jacob / Shafiq 被写成钱 + 技术员 + 政治人脉。
- 能力线、商业线和关系线分别推进，最后靠几场对话勉强连接。
- 技术升级不改变任何人物关系、权利结构或社会后果。
- Alexis 一个人拥有全部知识产权和决定权，Fred / George、Shafiq 技术人员等人的贡献消失。
- 所有合作都无条件成功，专业团队从不否定 Alexis。
- Shafiq 的家族“中立”只是为了让他们随时站在正确一边。
- Draco 因恋爱天然比 Jacob 更有资格参与专业决策。
- Jacob 因年长几岁就变成父兄式管教者。
- 第六部失踪期间让 Jacob 停止自己的毕业和家族人生，只围绕 Eleanor 等待。
