# 第七章｜Eleanor / Alexis × Hermione / Ron / Ginny / Luna / Neville

> *“朋友群”不是一条关系。五个人与 Eleanor / Alexis 的信息量、价值冲突、相处方式和能改变她的部分都不同。重修时必须分别追踪，不能只用“主角团朋友”概括。*

# 一、Hermione：相似表象下，程度和动机并不相同

Hermione 与 Alexis 都爱学习、守住自己认定的正确、愿意为目标投入大量时间，因此很容易被写成镜像。但这条线必须先固定一个差异：

**Hermione 是非常认真的好学生；Alexis 的学习和准备已经发展成明显更严重的自我工具化与风险控制。**

Time-Turner、课程数量等表面相似不能把两人写成同程度问题。Hermione 的课程选择仍然主要来自学业兴趣与好学生标准；Alexis 则会把“我还能多做一点”直接连接到战争、救人、提前准备和自我消耗。

关系功能：

- Hermione 可以在学术方法、事实核对、规则和伦理上反驳 Alexis；
- Alexis 不会把平行世界历史、全部创伤和所有秘密向 Hermione 倾倒，Hermione 不是读者代言人；
- 女孩之间可以有私人感情谈话，但信息量必须符合真正的朋友关系，而不是作者解释剧情；
- Hermione 能更早明确意识到自己喜欢 Ron、并向一个可信任的女生朋友说出来，可以成为这条关系对 Hermione 自己人生的真实帮助；这不能反过来变成 Eleanor“指导她恋爱”。

需要继续保留 Hermione 自己与 Harry、Ron、学业、家养小精灵、政治和战争的独立线。

# 二、Ron：不要低估他的社会判断与现实感

Ron 与 Eleanor / Alexis 不需要成为最深的知己，但他应当拥有一种与 Hermione、Harry 都不同的价值：他长期生活在巫师家庭中，对学院偏见、纯血家族、校园传闻和“别人实际上会怎么看”具有现实经验。

二年级原稿里，他能够迅速识别 Shafiq 家族位置，也能理解 Alexis 在 Slytherin 的社会成本；Harry / Ron / Hermione 选择不让她参与某些调查，不只能解释成“瞒着她”，也可以包含“她已经因为 Draco 和密室问题被本院孤立，再让她带人进 Slytherin 会进一步恶化处境”的现实判断。

关系功能：

- Ron 可以指出 Alexis 在模型里忽略的日常社会后果；
- 他有资格对她生气、怀疑、保护或拒绝，不只负责笑点；
- 他和 Harry / Hermione 的决定不能总要等 Eleanor 认可；
- 他与 Draco 的敌意和变化也应有自己的历史，不只是跟随 Harry。

# 三、Ginny：信任不是服从，救命也不等于判断正确

Ginny 已经拥有第二部最完整的关系主线，后续不得重置。

二年级状态链固定为：

**暑假憧憬式好感 → 火车发现 Slytherin 而破裂 → 疏远与重新评价 → 第二学期夜游重接 → 有限且非对称信任 → Ginny 启动公共求助但被打断 → Alexis 私人接管 → 两人共同进入密室 → Ginny 在终局夺回自主权 → 善后留下裂缝。**

这条关系对 Ginny 自己的意义不是“她看穿了主角的问题”，而是：

- 她从“被六个哥哥保护 / 定义的小妹妹”进一步学习自己决定谁可信、什么时候求助、谁有权替她承担风险；
- 她可以感谢 Alexis 救命，同时拒绝把感谢转化成服从或原谅；
- 后续友谊必须带着这段真实历史继续，不允许第三部开学后像什么都没发生。

# 四、Luna：从关系破裂后的偶遇开始，而不是命定知己

Luna 进入 Alexis 生活的节点必须保留：火车上 Ginny 后知后觉发现 Alexis 是 Slytherin，Alexis 受伤离开熟人包厢，随后才遇见 Luna。

这让 Luna 的出现天然拥有一种功能：她不是来“治愈学院偏见”，而是在 Alexis 原有关系暂时断裂时，提供一条完全不同的信息与相处路径。

Luna 的独立性必须保留：

- 她有自己的父亲、《唱唱反调》、兴趣与判断习惯；
- 她可以观察到别人忽略的东西，也可以相信并不正确的东西；
- 非主流不等于真相；
- 她不承担“神秘地说一句就点醒主角”的预言机功能。

与 Alexis 的关系可以建立在“允许对方用不同方式看世界”上，而不是谁把谁改造成正常人。

# 五、Neville：不能只做 Eleanor 认知成长的教材

一年级飞行课是 Alexis 认知线的重要节点：她因为掌握另一世界历史而选择不干预，事后意识到“不作为也是选择”。但如果只从这个角度写，Neville 就会被工具化。

必须同时保留：

- Neville 自己经历害怕、羞辱、学习和勇气增长；
- Longbottom 家庭和第一次战争遗产对他的压力；
- 祖母对 Slytherin / 战争记忆的态度可以成为独立社会线，而不是专门针对 Alexis；
- 后续能力成长、DA 和战争选择必须属于 Neville 自己。

当前 Eleanor — Neville 的跨卷私人关系仍需进一步深化，不强行编造六卷亲密节点。

# 六、五个人分别知道什么

| 人物 | 可以知道 / 观察 | 不能默认知道 |
| --- | --- | --- |
| Hermione | 学校内大量现实事实、Alexis 的学习 / 伤势 / 公开关系、部分私人感情 | 平行世界历史、未被告知的创伤细节、她每次行动的真实目的 |
| Ron | 巫师家庭 / 纯血社会常识、校园关系、Weasley 家信息 | Alexis 的隐秘认知模型和全部技术 / 战争计划 |
| Ginny | 自己与 Alexis 的二年级经历、她曾经隐瞒 / 接管求助的事实 | 平行世界历史；Alexis 为什么提前知道日记轮廓 |
| Luna | 自己观察到的异常、非主流信息源、朋友之间的现实互动 | “因为她特别所以天然知道真相” |
| Neville | 自己与她的学校经历、公开战争信息 | 她早年如何根据另一世界历史判断他的事件 |

# 七、朋友群不是固定五人小队

这些人可以在不同阶段交叉成为朋友，但不要为了“群像”强行让所有人同时行动。真正的群像标准是：

- Eleanor 不在场时，他们之间仍有关系；
- 他们会互相选择、争吵、合作；
- 他们拥有 Eleanor 不知道的经历；
- Eleanor 的错误不会让所有人得出同一个结论；
- 他们各自的成长不会以“更理解 Eleanor”为终点。
